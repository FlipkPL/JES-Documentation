# Instrukcje użytkownika JES

Ten katalog będzie zawierał zatwierdzone instrukcje użytkownika. Materiały powinny być zgodne z aktualną wersją dostępną pod adresem [jes.edu.pl](https://jes.edu.pl).

Zawartość jest organizowana według zadań użytkownika, wraz z wymaganymi uprawnieniami i wymaganiami dotyczącymi przeglądarki.
