# JES

JES to aplikacja dostępna pod adresem [jes.edu.pl](https://jes.edu.pl).

Ten publiczny projekt służy jako **repozytorium dokumentacyjne**: opisuje przeznaczenie, historię, sposób użycia, dostępność i procesy utrzymania systemu. Kod źródłowy nie jest tutaj publikowany. Informacje pochodzące z aktualnej wersji JES zamieszczanej pod adresem jes.edu.pl mają pierwszeństwo wobec starych treści znajdujących się w istniejącym repozytorium.
