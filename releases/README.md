# Zatwierdzone wydania

Każdy opis wydania umieszczany w tym katalogu powinien być zgodny z faktycznie opublikowaną wersją JES i powinien zawierać co najmniej:

- numer wersji i datę wydania,
- zakres zmian,
- znane ograniczenia,
- opis wpływu na użytkowników,
- odnośniki do publicznych raportów i dowodów.
