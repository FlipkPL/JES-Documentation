# Publiczne dowody i raporty

Ten katalog przeznaczony jest na publiczne, zatwierdzone materiały potwierdzające działania zespołu lub opisujące stan jakości JES.

Przed publikacją należy usunąć:

- poświadczenia i klucze dostępowe,
- dane osobowe i dane użytkowników,
- poufne logi systemowe,
- szczegóły podatności niezgodnie z dokumentem dotyczącym bezpieczeństwa.
